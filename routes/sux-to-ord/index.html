Interpretation boundaries

This dataset provides historical reliability signals and does not make booking recommendations.

Connection timing values reflect historical arrival and onward departure timing patterns only. They do not confirm whether a specific passenger can complete a connection.

Not included in this dataset:

  • Ticket price / fare data
  • Booking availability / seat inventory
  • Terminal walking distance
  • Airport congestion patterns
  • TSA / security recheck time
  • Baggage recheck requirement
  • Official minimum connection time (MCT)
  • Real-time weather
  • Real-time flight inventory / live status
